# Budgefi editorial assets

This folder contains the approved word-free editorial asset sheet and twelve cropped PNG assets. Use these as restrained background or section accents, not as functional controls or replacements for the Lucide interface icon system.

- `budgefi-editorial-sheet-preview.png` — review sheet on Budgefi paper
- `budgefi-editorial-sheet-transparent.png` — transparent master sheet
- `pencil.png`, `receipt.png`, `binder-clip.png`, `index-tab.png`
- `security-shield.png`, `ledger-folios.png`, `audit-seal.png`, `adding-machine.png`
- `folded-page.png`, `evidence-trail.png`, `bank-source.png`, `registration-marks.png`

Keep decorative assets behind content, preserve generous negative space, and use no more than one dominant decorative object per viewport.
