# Budgefi interactive demo

A mobile-first financial-operations prototype focused on reconciling expected and observed activity, requiring approval, and preserving evidence through verification.

## Local development

```sh
npm install
npm run dev
```

## GitHub Pages

Pushes to `main` build and publish the demo through the included GitHub Pages workflow. The production build uses hash routing so every interactive route works when hosted beneath a repository path.

This is a local interaction sample. Authentication, financial connections, household access, email, notifications, and money movement are not production services.
